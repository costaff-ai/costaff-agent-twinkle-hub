## 何時用本 skill

「文化 / 藝術 / 古蹟 / 歷史建築 / 博物館 / 美術館 / 展覽 / 藝文活動 / 補助 / ISBN / 出版品 / 古籍 / 客家 / 原住民 / 故宮 / 文資 / 民俗 / 文化部」相關時優先載入. **不適用於**: 私人畫廊 / 私人博物館、個人藝術家公開資料 (除非官方補助名單)、商業表演售票 (商業).

## 最佳實踐

1. **古蹟「指定」vs「登錄」**: 古蹟用「指定」, 歷史建築用「登錄」, 文資詞彙嚴謹
2. **agency 改制**: 文資局 vs 文資保存研究中心 (2014 後改制); 故宮南院 / 故宮北院 共享 dataset
3. **典藏品識別**: 故宮用「文物統一編號」, e.g. `故畫 001234`
4. **ISBN 13 vs 10**: 國圖 dataset 多為 13 碼 (978/979 開頭), 老 10 碼會有
5. **原民族別**: 官方認定 16 族 (阿美/泰雅/排灣/布農/卑南/魯凱/鄒/賽夏/雅美/邵/噶瑪蘭/太魯閣/撒奇萊雅/賽德克/拉阿魯哇/卡那卡那富)

## 注意事項

- 故宮典藏品影像授權多為 CC0, 但部分有版權限制, 用前看 metadata
- 民俗類資產有時敏感 (宗教/原民), 學術引用前看主管機關注釋
- 補助案 dataset 含「申請人 / 補助金額 / 案件名稱」, 屬公開資料

## 與其他 skill 的邊界

- **文化資產相關訴訟 (古蹟拆除 / 文資保存)** → `tw-opendata-judicial`
- **文化部政府採購 (修復工程 / 藝文計畫)** → `tw-opendata-pcc`
- **文化法案** → `tw-opendata-ly`, search「文化資產保存法」「文化基本法」
- **博物館 / 美術館 經緯度** → `tw-opendata-geo`
- **客家 / 原民相關地理空間** → `tw-opendata-geo` (e.g. 原民保留地)
