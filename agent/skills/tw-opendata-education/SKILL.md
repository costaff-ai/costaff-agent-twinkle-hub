## 學制速查

```
學前教育: 幼兒園 (2-6 歲)
國民教育: 國小 6 年 + 國中 3 年 (6-15 歲)
高中職:   高中 / 高職 / 五專 (3-5 年)
高等教育: 大學 4 年 + 研究所 (碩士 2-4 年, 博士 4-7 年)
特殊教育: 啟智 / 啟聰 / 視障 / 資優
技職教育: 高職 / 二專 / 四技 / 二技
```

## 最佳實踐

1. **agency 改制**: 「體育委員會」(2013 前) / 「體育署」(2013+); 「青輔會」/「青年發展署」; 兩個都試
2. **「國民」vs「國立」**: 國民 = 國家義務教育 (國中小), 國立 = 中央政府辦的 (國立大學), 別混
3. **「學年度」vs「年度」**: 學年度 = 8/1-7/31 (e.g. 113 學年度 = 2024-08-01 ~ 2025-07-31), 統計時要區分
4. **「校數」單位**: 一個學校可有「分校」「分部」, dataset 內 row 數可能 > 校數, 要看 schema
5. **「招生」vs「報到」**: 招生名額 ≠ 實際入學, 看 dataset 取哪個

## 注意事項

- 學生個資 (姓名/身分證/成績) 不公開, 政府只開放彙整統計
- **少子化** 趨勢明顯, 比較跨年資料時要看人口背景 (cross with `tw-opendata-population`)
- 私立學校 / 補習班數據 covered partial (only 立案數量, 不含營運細節)
- 大學部 vs 研究所 vs 進修部 vs 在職專班 各統計常分開, 解釋時要區分

## 與其他 skill 的邊界

- **教育相關訴訟 (學生事務 / 退學)** → `tw-opendata-judicial`
- **教育政府採購 (校舍 / 教科書)** → `tw-opendata-pcc`
- **教育法案** → `tw-opendata-ly`, search「國民教育法」「大學法」
- **大學研究專利** → `tw-opendata-patent`, applicant 含大學名
- **教師考試**(教檢/教甄) → `tw-opendata-exam`, exam_type 含「教師資格考」「教師甄試」
- **學區與地理座標** → `tw-opendata-geo` (各縣市學區劃分 SHP)
- **校園採購 / 招生政府支出** → `tw-opendata-pcc`
- **教育部所屬大學招生** → 本 skill, search「招生」
