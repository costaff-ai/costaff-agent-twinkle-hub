## 能源指標速查

```
能源消費總量 (公噸油當量, KOE)

裝置容量 (MW)

排碳係數: 每度電 kgCO2e (台電發布, 年度更新)
```

## 最佳實踐

1. **agency 改制**: 「能源局」(舊) vs「能源署」(2023.09); 兩個都試
2. **「裝置容量」≠「發電量」**: 前者是設備總和 (MW), 後者是實際輸出 (kWh / 億度), 容量不一定全發
3. **油價 vs 油類**: 95 / 92 / 98 三種無鉛, 柴油另算, 別混
4. **電價分級**: 住宅有累進 (用越多越貴), 工業/商業不同 tariff, 解讀要分
5. **再生能源計入**: 我國目標 2025 年 20% (現約 8-10%), 比較時要看年度
6. **核能爭議**: 核四 (停工) / 核一/二/三 (除役) 都已歷史化, 不要混

## 注意事項

- 即時即時油電 (RTP 動態電價, 即時油價變動) **不在本 batch corpus**, 商業 app 適合
- 再生能源 dataset 部分包含併網 vs 裝置 vs 發電量, 三個不同, 看 dataset
- 「碳排」係數常滯後 6-12 個月 (年度發布)
- 經濟部能源署 dataset 有「能源結構」「能源平衡表」「能源消費」等, 看細項選對

## 與其他 skill 的邊界

- **電費 / 油價相關訴訟** → `tw-opendata-judicial`
- **能源相關政府採購 (太陽能標案 / 核電廠工程)** → `tw-opendata-pcc`
- **能源法案 (能源管理法 / 再生能源條例)** → `tw-opendata-ly`
- **能源相關專利 (太陽能 cells / 風電技術)** → `tw-opendata-patent`, IPC H02S / H02P
- **環境影響 (空污排放, 與燃煤電廠關聯)** → `tw-opendata-environment`
- **CPI 中能源/油類項目** → `tw-opendata-finance` (主計總處)
