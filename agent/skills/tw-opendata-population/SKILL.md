# tw-opendata-population — 人口戶政與選舉資料

## Corpus 概況

| 主管機關 | dataset 數量 (~) | 典型內容 |
|---|---|---|
| 內政部戶政司 | 400+ | 全國人口 (年齡/性別/縣市/鄉鎮)、出生/死亡/結婚/離婚、戶數、人口密度 |
| 中央選舉委員會 (CEC) | 200+ | 歷次總統/立委/縣市長/議員/里長 投開票結果 |
| 內政部社會司 / 社家署 | 200+ | 社福機構、兒少保護、老人福利、身心障礙、低收入戶 |
| 入出國及移民署 (NIA) | 150+ | 外籍人士、新住民、入出境、居留人數 |
| 內政部地政司 (人口地理) | 50+ | 人口分佈圖層 |
| 涵蓋更新頻率 | — | 每月 (人口) / 每年 (社福統計) / 不定期 (選舉每 4 年) |

## 何時用本 skill

「人口 / 戶政 / 戶數 / 出生 / 死亡 / 結婚 / 離婚 / 高齡 / 少子化 / 選舉 / 投票 / 選區 / 立委 / 縣市長 / 里長 / 社福 / 兒少 / 老人 / 身障 / 低收入 / 新住民 / 移民 / 外籍」相關時優先載入. **不適用於**: 個別個資 (姓名/地址)、國外人口/選舉.

## 戶政術語速查

```
人口 vs 戶數    一戶可多人, 戶政 dataset 兩個都有
總人口          含外籍?  通常 = 設籍人口 (本國籍 + 永久居留)
社會增加        遷入 - 遷出
自然增加        出生 - 死亡
人口密度        人/km², 內政部按行政區計算
扶養比          (0-14 + 65+) / (15-64), 老化指標
老化指數        65+ / 0-14 ×100, 越高越老齡化
總生育率        每千女性 (15-49 歲) 一生平均生育子女數
```

## 最佳實踐

1. **設籍人口 ≠ 居住人口**: 學生戶籍在家鄉但住外縣市常見, dataset 多統計設籍
2. **「人」vs「次」**: 人是個人, 次是次數 (e.g. 結婚次數 1 人可多次), 看 dataset
3. **選舉投開票所**: 一個選區多個投開票所, 統計層級看 dataset
4. **agency 改制**: 內政部社會司 → 部分轉衛福部社家署 (2013), 兩個都試
5. **「外籍人士」分**: 外籍勞工 (移工, 在 labor skill) / 一般外籍 (居留) / 新住民 (婚姻取得身份), 三類分開
6. **歷史人口資料**: 部分回溯到 1956 (戰後), 學術研究適用

## 注意事項

- 個人戶籍資料**不公開** (個資保護), 只開放彙整統計
- 投開票所層級資料 (e.g. 某里第 N 投開票所) 可細到 200-500 人單位
- 公投 / 罷免 結果格式跟一般選舉不同, 看 dataset

## 與其他 skill 的邊界

- **戶政相關訴訟 (繼承 / 婚姻 / 收養)** → `tw-opendata-judicial`, case_type="家事"
- **選舉政治獻金 / 選舉公報** → 中選會 (本 skill) + 監察院 (在 catalog general)
- **戶政事務所地址 + 經緯度** → `tw-opendata-geo`
- **選舉法案 / 選罷法** → `tw-opendata-ly`
- **少子高齡相關政策** → `tw-opendata-general` (國發會少子化辦公室)
- **學生人口** → `tw-opendata-education`
